## Completed Projects

### Project 2 – Regression for Price Prediction

A supervised machine learning project focused on predicting house values using the California Housing dataset.

Key techniques used:

- Data preprocessing
- Feature engineering
- Linear Regression
- Random Forest Regression
- Cross-validation
- Hyperparameter tuning
- Model evaluation
- Feature importance analysis
- Model serialization using Joblib

### Project 3 – Customer Clustering and Segmentation

An unsupervised machine learning project focused on grouping customers based on purchasing behaviour using the UCI Online Retail dataset.

Key techniques used:

- Data cleaning and preprocessing
- Customer-level feature engineering
- StandardScaler
- K-Means clustering
- DBSCAN clustering
- Silhouette Score
- PCA
- Data visualization
